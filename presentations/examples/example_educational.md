## Chart Types

| Chart Type   | Use Case                    |
|--------------|-----------------------------|
| Bar Chart    | Comparing categories         |
| Line Chart   | Trends over time            |
| Scatter Plot | Relationships between vars  |
| Boxplot      | Distribution comparison     |
